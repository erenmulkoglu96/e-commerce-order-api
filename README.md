
# ECommerceOrderApi


ECommerceOrderApi, basit bir e-ticaret sistemi için geliştirilen sipariş yönetim servisidir. Kullanıcılar, ürünler ve siparişler gibi temel varlıklar üzerinde CRUD işlemleri yapılabilir. Ayrıca sipariş oluşturma, listeleme ve detay görüntüleme gibi API uç noktaları sunar. Projede Entity Framework Core, RESTful servis mimarisi ve In-Memory veritabanı kullanılmıştır.

(ECommerceOrderApi is an order management service developed for a basic e-commerce system. It provides API endpoints for CRUD operations on core entities such as users, products, and orders. The project includes features like order creation, listing, and detail view. Technologies used include Entity Framework Core, RESTful service architecture, and an In-Memory database.)


E-ticaret siparişlerini yönetmek için basit ASP.NET Core Web API'si.
(Simple ASP.NET Core Web API for managing e-commerce orders.)


## Features
- Yeni siparişler ekle (stok kontrol edildi) - Add new orders (stock checked)
- Kullanıcı siparişlerini listele - List user orders
- Sipariş ayrıntılarını al - Get order details
- Siparişi kimliğe göre sil - Delete order by ID
